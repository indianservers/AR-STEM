# AR Math Arena Origin Marker

Print `ar_math_arena_origin_marker.svg` on A4 paper with marker width set to 18 cm.

Coordinate definition:

- Origin: center of the printed marker.
- +X: marker right.
- +Y: normal outward from the marker plane.
- +Z: marker arrow forward.
- Units: metres.
- Rotation: normalized quaternion.

The QR join area is intentionally inside a low-detail box and should not cover the high-contrast tracking features. The QR code is only for joining the local room; AR tracking uses the full printed marker image.
