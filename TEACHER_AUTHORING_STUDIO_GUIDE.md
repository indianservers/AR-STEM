# Teacher Authoring Studio Guide

## Entry Point

Open `Games Library`, then choose `Teacher Authoring Studio`.

## Main Sections

- Mission Builder: creates validated AR math missions with prompt, answer, hints, worked solution, AR interaction type and accessibility fallback.
- Campaign Builder: groups campaign chapters and skill progression.
- Game Presets: stores reusable game duration, roles, difficulty, network mode and accessibility defaults.
- Tournament Presets: stores event format, game mix, team size, scoring weights and replay setting.
- Math Expedition Routes: documents the approved route workflow for outdoor missions.
- Content Packs: exports and validates local packs.
- Preview And Test: runs missions without changing progress or badges.
- Validation Reports: surfaces publishing blockers.
- School Settings: local display defaults and approval rules.
- Backup And Restore: local backup package selection and restore checks.

## Publishing Rule

A mission must pass validation and complete preview before it becomes publish-ready.
